# Лабораторная работа №15. Todo-list на Angular

## Запуск

Выполните `npm install`, затем `npm start` в этой папке и откройте адрес, указанный Angular CLI. Для проверки production-сборки выполните `npm run build`.

## MVC-структура

- `src/app/models/todo.model.ts` описывает задачу.
- `src/app/services/todo.service.ts` хранит список и реализует добавление, переключение статуса и удаление; сервис внедряется в контроллер через DI.
- `src/app/controllers/todo.controller.ts` обрабатывает действия пользователя и передаёт состояние представлению.
- `src/app/views/todo-view.component.html` и `todo-view.component.css` задают шаблон и оформление.
- `src/app/app.module.ts` подключает `FormsModule`, необходимый для `[(ngModel)]`.

В проекте используются двусторонняя привязка `[(ngModel)]`, `*ngFor` и `*ngIf`. Список пуст при первом запуске; задачи хранятся в сервисе в памяти до перезагрузки страницы.

## Angular и React

В этом проекте Angular разделяет шаблон, компонент-контроллер и сервис, а `[(ngModel)]` обновляет поле компонента через двустороннюю привязку. В React мне привычнее явно передавать обработчики через props и обновлять состояние через `useState`; Angular-сервис с DI централизует состояние и не требует передавать его через цепочку компонентов. Необычнее всего было подключать `FormsModule` и описывать список и условия прямо в шаблоне.
