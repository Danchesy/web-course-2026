# Лабораторная работа №14. Тестирование приложения

Тесты проверяют модель и компоненты Todo-list из [task11](../task11). Для запуска перейдите в эту папку, выполните `npm install`, затем `npm test`.

Проверены 11 сценариев модели: фильтрация, пустые данные, сортировки, сохранение исходного массива, статистика и генерация id. Ещё 5 тестов проверяют рендер формы, добавление очищенного от пробелов текста, запрет пустого ввода, удаление и переключение задачи с правильным id. Покрыто примерно 75% функций модели; сетевые запросы, визуальная раскладка и интеграция с json-server не включены, поскольку это отдельные интеграционные сценарии.

Среда запуска настроена через Vitest, jsdom и React Testing Library.

Последний успешный запуск:

```text
> npm test
Test Files  3 passed (3)
Tests       16 passed (16)
```
