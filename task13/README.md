# zen-money

Учебный проект на next.js: список доходов и расходов, создание операции и подробная страница.

## запуск

```bash
npm install
npm run dev
```

Откройте `http://localhost:3000`. При первом запросе к api приложение создаёт `zen-money.sqlite` и наполняет базу данными из `db.json`. Файлы sqlite исключены из git.

## маршруты и api

- `/` — сводка, история и фильтры операций.
- `/add` — форма создания операции.
- `/transaction/[id]` — подробности одной операции.
- `GET /api/categories` — получить категории.
- `POST /api/categories` — создать категорию.
- `GET /api/transactions?type=expense&category=Еда&dateFrom=2026-10-01&dateTo=2026-10-31` — получить операции с необязательными фильтрами.
- `POST /api/transactions` — создать операцию.
- `GET /api/transactions/[id]` — получить одну операцию.
- `PUT /api/transactions/[id]` — обновить операцию.
- `DELETE /api/transactions/[id]` — удалить операцию.

Обработчики api находятся в `app/api`. Общая работа с sqlite вынесена в `lib/db.js`; в пределах процесса соединение переиспользуется. Модель в `src/models` отправляет запросы на внутренние адреса `/api/...`, контроллеры управляют состоянием, а представления показывают интерфейс. Страница списка и отдельная страница добавления используют `next/link` для навигации.

В папках лабораторных 8–9 этого репозитория находился json-server, а не Express и SQLite. В этой работе я сохранил формат данных и основные сценарии api, заменив json-server на route handlers Next.js и SQLite.

## архитектура и рендеринг

Route handlers и Express-обработчики принимают HTTP-запрос, выполняют серверную логику и возвращают HTTP-ответ; в этом проекте обработчики Next.js являются частью приложения, а не отдельным Express-сервером на другом порту. Список и подробности загружают данные в браузере — это csr; при ssr сервер сформировал бы html с данными на каждый запрос, а при ssg html был бы сформирован заранее во время сборки. Для меняющихся операций ssg требует механизма обновления, иначе страница будет показывать устаревшие данные.

## публикация

Импортируйте репозиторий в vercel и укажите `task13` как корневую папку; команды сборки и запуска next.js определяются автоматически. После публикации добавьте ссылку на сайт сюда.

В среде vercel база создаётся в `/tmp`. Это позволяет route handlers читать и изменять SQLite во время работы, но файловая система serverless-окружения временная: данные могут пропасть после перезапуска, а разные экземпляры приложения не обязаны видеть один и тот же файл. Практическую проверку этой особенности нужно выполнить после деплоя; для постоянного общего хранилища потребуется внешняя база данных.
